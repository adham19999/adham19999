## Featured Projects

<details>
<summary><b>Hnefatafl — Viking Chess AI</b> &nbsp;·&nbsp; Python · Prolog</summary>
<br/>

An 11×11 asymmetric Viking strategy game with a full AI opponent built in SWI-Prolog and a dark-themed Python GUI. The AI uses Minimax search with Alpha-Beta Pruning across configurable depth levels, with a custom heuristic evaluating material balance, king proximity to escape corners, and king threat exposure.

| Attribute | Details |
|-----------|---------|
| Stack | Python · SWI-Prolog · Tkinter |
| AI Algorithm | Minimax + Alpha-Beta Pruning (depth 1–5) |
| Architecture | Python ↔ Prolog subprocess bridge |
| Game Modes | Human vs Human · Human vs AI (attacker or defender) |
| Performance | Time-limited search with depth-1 fallback |
| Repository | [hnefatafl-viking-chess](https://github.com/adham19999/hnefatafl-viking-chess) |

All game rules — movement, sandwich captures, throne/corner restrictions, and win detection — are implemented as pure Prolog predicates. AI moves run on a background thread to keep the GUI fully responsive.
